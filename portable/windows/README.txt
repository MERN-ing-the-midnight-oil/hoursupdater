Teamster Tracker — portable Windows package
==========================================

This folder runs on your PC. Your shared data lives in OneDrive.

Quick start
-----------
1. Read SETUP-ONEDRIVE.md and create the OneDrive folder.
2. Copy .env.example to .env (if .env is not already here).
3. Edit .env — set DATA_DIR to that OneDrive folder's full path.
4. Double-click Start.bat.
5. Use the app in Edge at http://localhost:3847
6. Leave the black window open while you work. Close it to stop.

If something goes wrong
-----------------------
Open TROUBLESHOOTING.md in this folder.

Do NOT put this whole app folder inside OneDrive.
Only the DATA_DIR folder (RouteChangeTracker) belongs on OneDrive.
