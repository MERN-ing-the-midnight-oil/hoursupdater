# Archived page — My Teamster Contract Date Calculator

This folder is the public calculator page that drivers used to type in their own clock times and see a predicted contract date. It is no longer published.

The files here are a copy of that page: `index.html`, `app.js`, `styles.css`, and `clock-hours-guide.html`. The live site is the read-only route change history page in `employee-tracker/web`.

The calculation code the office dashboard still uses stays in `employee-tracker/src` and `employee-tracker/web/engine.js`. It was not part of this archived page.
