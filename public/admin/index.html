Routing Admin Drivers How this app works

Admin queue

Read-only view of routes by status. Confirm the shape here before resolve actions, letters, and workbook tools land in later pieces.

Needs Review 0

Finalized status flips held for Admin, plus recent self-resolved review flags so ping-ponging stays visible.

Accumulating 0

Open 15-school-day windows with exact cumulative drift and contributing changes.

Bid Pending 0

Windows that finalized at or above the bid threshold — still waiting on bidding.

Pending Changes 0

Changes queued behind an open review — will process once that review is resolved.

Stable 0

Informational only — collapsed by default so attention stays on active work.

Settings

School calendar and payroll notification settings are editable here. Other settings (staff names, drivers, adjustment reasons) land in a later piece.

Payroll notification

Used by Notify Payroll on bid-pending routes in the Admin queue. Opens a mailto draft — the app never sends email itself.

Placeholders: {{route_id}}, {{driver_name}}, {{driver_email}} — missing values are left blank.

School calendar

Coverage is the full civil-day list with is_school_day flags. Add/remove toggles school days inside that range (snow days / makeups) — the 15-day window only counts dates marked as school days.
