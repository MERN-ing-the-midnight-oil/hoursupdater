Admin Settings

Staff names, reason categories, notifications, school calendar, email templates, and Archive Year & Import New Roster are editable here. Other settings (adjustment reasons) land in a later piece.

Staff names

Names shown in Entered by / Adjusted by dropdowns across Routing and Admin. Add each person’s display name exactly as it should appear.

    Reason categories

    Options shown in the Reason category dropdown on the Routing form (for example MV, SPED, OTHER).

      Email templates

      One template per trigger event. When an event fires, Admin gets an in-app prompt to open a draft in your system default email app — the app never sends email itself.

      PAYROLL EMAIL

      Used when a template’s recipient is payroll (contracted-hours change notice). Saved on the shared server so every device sees the same addresses.

      Separate multiple CC addresses with commas.

      Notifications

      A desktop pop-up is a real notification from your computer, like from any other app. It can appear even if you are looking at something else — but only while this Admin browser tab is open. These preferences stay on this device only.

      Quiet hours

      Quiet hours can wrap midnight (for example 6:00 PM to 8:00 AM).

      Customize which events

      Turn off specific situations if you do not want alerts for them on this browser.

      Paper bid sign-up

      Disabled

      When a route becomes bid-eligible, Admin is offered a printable sign-up sheet (Art. 3.08(c)(1) — initial next to their name). Leave this off if you are not using paper sheets for open bids.

      Paper bid feature

      Disabled — no print-sheet prompts

      Sheet template

      Title, intro, and footer on the printable sign-up sheet. The printed header always includes route, full schedule (AM / Midday / PM), and the start date you set per route.

      Placeholders: {{route_id}}, {{driver_name}}, {{bid_response_due_date}}, {{start_date}}, {{schedule}}.

      Electronic bid sign-up

      Disabled

      Replaces the paper “initial next to their name” sheet (Art. 3.08(c)(1)) once the office and Union have formally agreed. Leave this off until that agreement is in place — while off, Notify drivers and the Forms sign-up record stay dormant and are not treated as authoritative.

      E-bid feature

      Disabled — paper sign-up remains in effect

      School calendar

      Coverage is the full civil-day list with is_school_day flags. Add/remove toggles school days inside that range (snow days / makeups) — the 15-school-day window only counts dates marked as school days.

      Generate a school year

      Build weekdays between first and last day, apply breaks/holidays, pad surrounding summer coverage, then preview before writing.

      Archive Year & Import New Roster

      Use this when starting a new school year. When there is existing data, archive it first (a file copy — nothing is deleted), then import the new roster as a separate step.

      Step 1: Archive current year

      The archive is a copy of everything under _app_data plus the current RouteChangeTracker.xlsx. You name the folder yourself (for example, 2025-26 school year). There is no in-app archive viewer yet — open the files in Excel, or ask Cursor later if a viewer becomes useful.

      Admin queue

      Read-only view of routes by status.

      Needs Review

      Finalized status flips held for Admin, plus recent self-resolved review flags so ping-ponging stays visible.

      Accumulating

      Open 15-school-day windows with accumulated time difference and contributing changes.

      Bid Pending

      Windows that finalized with an increase of 30 minutes or more — waiting on bidding.

      Bump Eligible

      Windows that finalized with a decrease of 30 minutes or more — current driver has two school days to bump or keep the assignment.

      Pending Changes

      Changes queued behind an open review — will process once that review is resolved.

      Stable

      Informational only — collapsed by default so attention stays on active work.
