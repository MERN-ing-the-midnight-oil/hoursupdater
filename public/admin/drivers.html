Routing Admin Drivers/Routes Definitions

Drivers/Routes

Directory of drivers, plus deliberate tools to add a driver or change who holds a route. Assignments never reset window status or drift.

Resolve seniority ties

The contract requires same-date ties to be resolved by drawing lots.

Put the most senior driver first for each hire date (after the office has drawn lots). Recording order writes tie-break values and clears that warning — this screen only records the outcome.

    Tools

    Each tool starts closed. Assignment tools require staff attribution, a note, typed confirmation, and an explicit acknowledgment before they can run.

    Add new driver

    Adds someone to the directory only — does not assign a route. Hire date is required for seniority.

    Assign driver to a route

    Start with the driver, then choose which route they should hold. This replaces whoever is currently on that route.

    Assign route to a driver

    Start with the route, then choose which driver (or Unassigned) should hold it.
